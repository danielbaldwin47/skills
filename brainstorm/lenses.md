# Lenses

One entry per lens. The diverge pass reads this file and produces 1–3 ideas per **default** lens; **held-back** lenses come in on follow-up rounds or when the user names them. Edit freely — add, cut, reword. The `## Lens notes` line in each brainstorm doc records which lenses produced standouts; use it to prune.

Tag format in the idea list: `[name]` — use the short name in the left column.

## Default

| tag | prompt the model applies |
|---|---|
| `obvious` | The first sensible answer a competent person would give. Say it plainly; it belongs on the list. |
| `inversion` | Do the opposite of the obvious. Reverse the actor, the direction, the goal, or the order. |
| `borrow` | How does an unrelated field solve this shape of problem? Lift the mechanism, not the metaphor. |
| `remove-constraint` | Pick one constraint the user stated or implied and delete it. What becomes possible? |
| `add-constraint` | Impose a harsh new limit — one day, zero budget, no code, one sentence — and answer under it. |
| `cheapest` | The smallest thing that could plausibly work. Embarrassingly small is fine. |
| `most-ambitious` | The version that would matter in five years. Ignore feasibility for one line. |
| `question-premise` | Challenge an assumption in the topic itself. Is the problem the problem? |

## Held back

| tag | prompt the model applies |
|---|---|
| `combine` | Fuse two ideas already on the list into one that neither is alone. |
| `archetype` | What would a named kind of person do — a hacker, a monk, a toddler, a Victorian engineer? Pick one, answer as them. |
